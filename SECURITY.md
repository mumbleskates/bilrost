# security policy

## supported versions

Currently the 5 most recent semver branches of `bilrost` are supported with
updates for security and correctness.

## reporting a vulnerability

Vulnerabilities and correctness bugs can be reported [on
github](https://github.com/mumbleskates/bilrost/security) or by email to
[security@mad.cash](mailto:security@mad.cash). Security vulnerabilities are
prioritized and remediation will be coordinated with downstream project
maintainers where applicable.

Downstream project maintainers and users can request participation in
coordination of applicable security issues by sending your contact email
address, GitHub username(s) and any other salient information by email to
[security@mad.cash](mailto:security@mad.cash). Participation in security issue
coordination processes is at the discretion of the maintainers.

## security advisories

Security issues are announced in the changelog and to the [rustsec advisory
database](https://rustsec.org/).
